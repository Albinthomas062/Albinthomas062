# Palette's Journal

## 2025-05-18 - Missing Alt Text in GitHub Profile README Graphics
**Learning:** Profile READMEs frequently use custom SVG/dynamic API graphics (capsule banners, skill icons, stats cards, badge links) via `<img>` tags without `alt` attributes. This leaves screen readers unable to convey meaningful content or destinations for interactive elements, resulting in a confusing experience for assistive technology users.
**Action:** Always provide descriptive and concise `alt` text for informative graphics and badges, explaining the represented technologies, statistics, or navigation targets, and verify against MD045.
