## 2026-11-09 - Markdown Profile Accessibility
**Learning:** Profile READMEs composed of SVG widgets, dynamic badges, and skill icons frequently omit `alt` attributes and link aria-labels, leaving assistive tech users unable to perceive tech stacks, stats, or contact links.
**Action:** When working on Markdown profile representations, always provide descriptive `alt` texts on dynamic badges and `aria-label`s on icon-only links.
