## 2026-10-12 - Profile README Accessible Image Badges
**Learning:** External SVGs, skill icon grids, stats widgets, and badge links in GitHub Profile READMEs often lack descriptive `alt` text or default to generic labels like `"Typing SVG"`, rendering them invisible or uninformative to screen readers.
**Action:** When working on Markdown/HTML README profiles, inspect all `<img>` tags and add explicit, descriptive `alt` attributes detailing the content of typing headers, tech stacks, stats, and social links.
