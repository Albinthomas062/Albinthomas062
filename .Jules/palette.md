## 2026-11-05 - Profile README Image Accessibility

**Learning:** GitHub profile README markdown files often include raw HTML `<img>` tags for widgets, banners, and shields badges that lack `alt` text. This renders them invisible or confusing to screen reader users and impairs fallback UX if external services fail to load.
**Action:** Always provide concise, descriptive `alt` text for informational widgets and tech stack icon groups, and mark purely decorative banners appropriately.
