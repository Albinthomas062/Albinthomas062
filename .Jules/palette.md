## 2026-03-31 - Add Alt Text to GitHub Profile README Graphics & Skill Icons
**Learning:** In markdown profile READMEs using embedded raw HTML `<img>` tags for skill badges, stats cards, and header banners, missing `alt` text causes screen readers to skip or misread images. Adding descriptive `alt` text directly improves accessibility for visual assets in GitHub profiles.
**Action:** When working on Markdown or profile repos with embedded HTML images, audit all `<img>` tags and badges to ensure informative `alt` attributes are present.
